REQUEST MANAGEMENT

Viewer requests without the copy-paste circus.

Turn Twitch beatmap links into an organized queue with map data, request rules and controls built for the streamer.

Queue & review

Open or close requests, set queue and per-viewer limits, review maps before they enter the active queue and retain session history.

Optional map filters

Set Min/Max limits for PP, length, BPM, AR, CS and OD—or leave any filter blank when you do not want that restriction.

Requested mods

Keep requested mods attached to each map so the original request does not get lost between chat and gameplay.

Request overlays

Add Current Map, Compact Queue and Map Requests Open as independent OBS Browser Sources with customizable size, opacity, alignment and positioning.

!np chat command

Let viewers ask for the current or most recently opened requested map without interrupting the stream.

osu!stable + lazer

Choose the osu! client you use and open requested maps directly while preserving queue and history information.

KEY VISUALIZER

A smooth, customizable input overlay for osu! streams.

Run the visualizer as its own OBS Browser Source and style each input independently.

60 FPS overlay

The browser overlay targets roughly 60 frames per second for smoother key presses and trails.

Independent press colors

Customize Key 1 and Key 2 separately, with optional individual colors for Mouse 1 and Mouse 2.

Custom trail color

Choose a separate trail color with its own preview and hex value instead of inheriting a key color.

Adjustable trails

Fine-tune trail height, width and duration with direct input and selector controls.

Background capture

Capture supported letters, numbers, punctuation, arrows, modifiers and mouse buttons while the app is minimized.

Cumulative total

The counter tracks total presses across enabled inputs and resets only when you deliberately reset it.

RANKED PLAY

Ranked tracking without another separate utility.

The Ranked Play Tracker has its own dedicated screen, persistent Save and Refresh controls, and sits alongside the request and overlay tools.

COMMON QUESTIONS

Quick answers.

Does the Key Visualizer work while the app is minimized?

Yes. Supported keyboard and mouse bindings are captured in the background for the browser overlay.

Can each key and trail use a different color?

Yes. Key 1, Key 2, optional mouse inputs and the trail color are independently customizable.

Does the total reset every second?

No. It is cumulative and resets only through Reset Counters or when the application restarts.

Can I use the visualizer with the request overlays?

Yes. They are separate Browser Sources, so you can use one or several together.
