WHAT IT DOES

Viewer requests without the copy-paste circus.

Viewers paste osu! beatmap links in Twitch chat. osu!Requests turns them into a manageable queue with map data, request rules, streamer controls and optional stream overlays.

Queue & review

Open or close requests, set queue and per-viewer limits, optionally review requests before they enter the active queue, and keep a session history.

Map filters

Optional Min/Max limits for PP, length, BPM, AR, CS and OD. Leave them blank when you want to allow any map.

Requested mods

Keep common mod requests attached to the map so the streamer does not have to reconstruct what chat asked for.

OBS overlays

Use Current Map, Compact Queue and Map Requests Open as separate OBS Browser Sources with customizable layout, opacity and positioning.

Key Visualizer

Display key and mouse presses in a smooth 60 FPS browser overlay with independent Key 1, Key 2, mouse and trail colors, adjustable trails and a cumulative total counter.

Ranked Play Tracker

Track ranked play information from its own dedicated workspace, with persistent controls and manual refresh.

!np chat command

Viewers can type !np to see the current or most recently opened requested map.

osu!stable + lazer

Choose your preferred osu! client and open requested maps directly from the app while keeping history intact.

COMMON QUESTIONS

Quick answers.

Does the Key Visualizer work while the app is minimized?

Yes. Supported keyboard and mouse bindings are captured in the background for the browser overlay.

Can each key use a different color?

Yes. Key 1, Key 2, optional mouse inputs and the trail color are independently customizable.

Can I use more than one OBS overlay?

Yes. The request overlays and Key Visualizer can be added as separate browser sources.
