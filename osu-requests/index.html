WHAT IT DOES

Viewer requests without the copy-paste circus.

Viewers paste osu! beatmap links in Twitch chat. osu!Requests turns them into a manageable queue with map data, request rules and streamer controls.

Queue & review

Open or close requests, set queue and per-viewer limits, optionally review requests before they enter the active queue, and keep a session history.

Map filters

Optional Min/Max limits for PP, length, BPM, AR, CS and OD. Leave them blank when you want to allow any map. PP is estimated for a 100% FC on the exact requested difficulty and includes requested mods.

Requested mods

Keep common mod requests attached to the map so the streamer does not have to reconstruct what chat asked for.

OBS overlays

Use Current Map, Compact Queue and Map Requests Open as separate OBS Browser Sources — one, several, or all at the same time. Customize colors, opacity and streamer label, resize the overlays, choose top/bottom queue growth, snap content left or right, and fine-tune X/Y positioning.

!np chat command

Viewers can type !np to see the current or most recently opened requested map without asking the streamer.

osu!stable + lazer

Choose your preferred osu! client and open requested maps directly from the app while keeping history intact.

COMMON QUESTIONS

Quick answers.

Is this an osu!lazer Twitch request bot?

Yes. osu!Requests is designed for both osu!lazer and osu!stable/classic on Windows.

Do I have to set PP, BPM, AR, CS, OD or map length limits?

No. Those filters are optional. Leave them blank to allow any map, and only set Min/Max values when you want specific request limits.

Can chat check the current map?

Yes. The built-in !np command can report the current or most recently opened requested map.

Can I use more than one OBS overlay?

Yes. Current Map, Compact Queue and Map Requests Open are separate browser-source overlays and can be used together.
