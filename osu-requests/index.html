REQUEST MANAGEMENT

Viewer requests without the copy-paste circus.

Turn Twitch beatmap links into an organized queue with map data, request rules and controls built for the streamer.

Queue & review

Open or close requests, set queue and per-viewer limits, review maps before they enter the active queue and retain session history.

Optional map filters

Set Min/Max limits for PP, length, BPM, AR, CS and OD—or leave any filter blank when you do not want that restriction.

Requested mods

Keep requested mods attached to each map so the original request does not get lost between chat and gameplay.

osu!stable + lazer

Choose the osu! client you use and open requested maps directly while preserving queue and history information.

!np chat command

Let viewers ask for the current or most recently opened requested map without interrupting the stream.

Request overlays

Add Current Map, Compact Queue and Map Requests Open as independent OBS Browser Sources with customizable size, opacity, alignment and positioning.

KEY VISUALIZER

A smoother input overlay built for osu! streams.

Run the visualizer as its own browser source and customize each input instead of forcing every key into one shared style.

60 FPS target

The browser overlay updates at roughly 60 frames per second for smoother presses and trails than the earlier 30 FPS behavior.

Independent key colors

Give Key 1 and Key 2 different press colors—blue and red, matching colors, or any combination that fits the stream layout.

Mouse colors

Optional Mouse 1 and Mouse 2 inputs can each use their own independently selected press color.

Custom trail color

Choose a separate trail color with a live preview and hex value, independent from all key and mouse press colors.

Adjustable trails

Fine-tune trail height, width and duration while keeping direct numeric input and convenient selector controls.

Background bindings

Capture common letters, numbers, arrows, modifiers and punctuation while the main app is minimized.

Cumulative total

The counter shows total presses across enabled keyboard and mouse inputs and only resets when you deliberately reset counters.

Dedicated settings

Key Visualizer settings live in their own workspace with visible Save and Refresh controls instead of being duplicated in Preferences.

RANKED PLAY

Track ranked information without leaving the app.

The Ranked Play Tracker has its own dedicated screen and refresh workflow alongside the request and overlay tools.

Dedicated tracker

Keep ranked play information separate from general preferences so the controls are easier to find during a session.

Save & refresh

Persistent Save and Refresh controls remain visible at the bottom of the tracker instead of being pushed out of view.

One osu! workspace

Request management, stream overlays, input visualization and ranked tracking stay available from one application.

COMMON QUESTIONS

Quick answers.

Does the Key Visualizer work while the app is minimized?

Yes. Supported keyboard and mouse bindings are captured in the background for the browser overlay.

Can each key and trail use a different color?

Yes. Key 1, Key 2, optional mouse inputs and the trail color are independently customizable.

Does the total reset every second?

No. It is cumulative and resets only through the Reset Counters control or when the application restarts.

Can I use the Key Visualizer with the request overlays?

Yes. They are separate browser sources, so you can use one or several together.
