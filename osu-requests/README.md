# osu!Requests

A Windows Twitch → osu! request manager and stream-side toolkit for **osu!stable** and **osu!lazer**.

> ### Streamer tools by ValoCookie
> osu!Requests handles Twitch map requests, OBS overlays, input visualization and Ranked Play tracking.  
> Looking for repeatable pre-stream preparation too? **[Check out StreamFlight →](https://github.com/ValoCookie/streamflight)**

## Latest release

The newest public build is always available from **[GitHub Releases](https://github.com/ValoCookie/osu-Requests/releases/latest)**.

## Highlights

- Twitch request queue, review mode, history, queue/per-user limits and optional map filters
- `!np`, viewer `!myq`, editable dual-client `!skin` / `!setskin` tools
- clean osu! chat delivery: NoMod has no `NM` label; modded requests show only the actual mods and no `Suggested` prefix
- Current Map, Compact Queue and Requests Open OBS Browser Sources
- customizable ~60 FPS Key Visualizer with cumulative TOTAL, live BPM / MAX BPM and horizontal/vertical layouts
- dual-input BPM handling so two-key streams are not shown at half-speed
- Ranked Play profile cards, session tracking, transparent OBS mode and fast live refresh
- portable in-place self-update flow that stages in TEMP, verifies the replacement and relaunches the same EXE path

## osu!stable + osu!lazer

Requested maps can be opened through Windows Default, osu!stable or osu!lazer. Skin reporting and relevant local detection features handle stable and lazer separately.

## Privacy

The public desktop app does not contain the private valocookie osu! credentials. Sensitive connection information is kept out of diagnostics exports.
