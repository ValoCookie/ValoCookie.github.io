osu!Requests

Twitch map requests for osu!stable and osu!lazer.

Manage viewer beatmap requests, queue rules, optional map filters, requested mods, history, OBS overlays and chat commands without juggling links mid-stream.

  • Twitch request queue + review mode
  • Optional PP / BPM / AR / CS / OD / length filters
  • Current Map, Compact Queue and Map Requests Open OBS overlays
  • !np for chat to see the current requested map
  • Customizable overlay sizing, colors and positioning
