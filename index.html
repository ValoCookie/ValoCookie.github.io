Two apps, each built to do one job well.

Use either app by itself, or pair them if you stream osu! and want both request management and consistent pre-stream preparation.

osu!Latest release

osuStreamDeck

Twitch requests, live overlays and ranked tools for osu!stable and osu!lazer.

Manage viewer beatmap requests while keeping now-playing information, skin commands, a customizable Key Visualizer and live Ranked Play information in the same application.

  • Twitch request queue, review mode, filters, !np and viewer !myq
  • Current Map, Compact Queue and Requests Open OBS Browser Sources
  • 60 FPS Key Visualizer with TOTAL, live BPM / MAX BPM and flexible layouts
  • Dual-client !skin detection with editable display names and links
  • Ranked Play profile stats, transparent mode and fast live refresh through the relay
  • In-place portable EXE updates with verified replacement and automatic relaunch

StreamFlight

A repeatable application, website and checklist workspace.

Prepare applications, browser tools and recurring checks before chat becomes the first person to tell you something is wrong.

  • Background helpers with hide and access hotkeys
  • Website launcher and reusable stream checklists

  • Readiness status and end-of-session cleanup
