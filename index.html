osu!Requests

Twitch → osu! map requests without the copy-paste circus.

Queue viewer requests, filter maps, keep request history, handle requested mods, manage approvals, and use OBS browser overlays for the current map and queue.

  • Twitch chat request queue
  • osu!stable + osu!lazer support
  • Optional BPM / AR / CS / OD / length filters
  • OBS current-map, compact-queue and status overlays

StreamFlight

A pre-stream workspace that checks the boring stuff before chat notices.

Run preflight checks around OBS and Windows, keep your stream checklist in one place, test recording, and catch setup problems before you hit Go Live.

  • OBS + Windows preflight checks
  • Stream checklist and session workflow
  • Recording/setup testing
  • Optional osu!Requests integration for osu! streamers

WHY GITHUB?

Updates without waiting on a storefront.

New builds can be published directly through GitHub Releases, so bug fixes and small improvements do not need to wait for a store submission cycle. The source stays public alongside the downloads.

DOWNLOAD NOTE

Windows may warn about newer unsigned builds.

These projects are public on GitHub so you can inspect the source and release history. Download builds only from the official ValoCookie repositories linked on this page. Never disable Windows security features just to install an app.
