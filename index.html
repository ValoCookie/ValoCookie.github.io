osu! Latest release

osu!StreamDeck

this used to just be osu! Requests. then i kept adding stuff, cuz people asked for features

It started as a Twitch beatmap request manager. Now it also does OBS overlays, the key visualizer, skin commands, Ranked Play stuff and anything else later on ig per request.

  • Twitch beatmap requests with queue controls, filters, !np and !myq
  • OBS overlays for current map, queue and request status
  • 60 FPS key visualizer with TOTAL, live BPM and MAX BPM
  • !skin support for osu!stable and osu!lazer
  • Ranked Play profile info and live updates
  • Update checks so you dont have to keep checking GitHub

StreamFlight

I kept forgetting a lot of things before stream so this exists now.

StreamFlight opens the apps and websites i use before going live, keeps my usual checks in one place, and helps stop the whole "oh right i forgot that" thing five minutes into stream.

  • Open apps in the order you want
  • Optional delays between launches
  • Website launcher and reusable checklists
  • Different profiles for different setups
  • Readiness tracking
  • End-of-session cleanup stuff
