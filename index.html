osu!StreamDeck

This used to literally just be osu! Requests. Then I kept adding shit.

It started as a way to handle Twitch beatmap requests without making my stream setup more annoying than it already was. Now it also does OBS overlays, key/BPM visualization, skin commands, Ranked Play stuff, and whatever else I decide it apparently needs next.

  • Twitch beatmap requests, queue controls, filters, !np and !myq
  • OBS overlays for your current map, queue and request status
  • 60 FPS Key Visualizer with TOTAL, live BPM and MAX BPM
  • !skin support for both osu!stable and osu!lazer
  • Ranked Play profile info and live updates
  • Automatic update checks because manually checking GitHub gets old fast

FLIGHTLatest release

StreamFlight

Because apparently remembering my own pre-stream setup was asking too much.

StreamFlight opens the apps and websites I need, keeps my usual checks in one place, and generally stops me from getting five minutes into stream before realizing I forgot something dumb.

  • Launch apps in the order you actually want them
  • Optional delays for apps that need a second to exist
  • Websites and reusable checklists
  • Different profiles for different games or setups
  • Readiness tracking so you can see what you forgot
  • Cleanup tools for when stream is finally over
