osu!Requests

Twitch map requests, overlays and ranked tools for osu!stable and osu!lazer.

Manage viewer beatmap requests while keeping OBS overlays, editable skin commands, live input-speed visualization and a Ranked Play Tracker in the same application.

  • Twitch request queue, review mode and optional map filters
  • Current Map, Compact Queue and Requests Open OBS overlays
  • 60 FPS Key Visualizer with background key and mouse capture
  • Horizontal or vertical visualizer layouts with independent key/mouse/trail colors
  • Cumulative press total and dedicated Ranked Play Tracker
  • !np, viewer !myq, and editable !skin chat tools

StreamFlight

A repeatable application, website and checklist workspace.

Prepare applications, browser tools and recurring checks before chat becomes the first person to tell you something is wrong.

  • Background helpers with hide/access hotkeys
  • Website launcher and reusable stream checklists
  • Multiple profiles for different games or formats
  • Readiness status and end-of-session cleanup controls
