APPLICATION STARTUP

Prepare once. Start consistently.

Build the application sequence once, then reuse it for every stream profile.

Ordered launch sequence

Add the applications used for a stream, choose their launch order and assign optional startup delays. Application entries can be reordered directly by dragging.

Drag-and-drop setup

Drop Windows executables or supported shortcuts into the application list and reorder entries directly.

Background helpers

Launch helper apps without leaving their windows in the way, including continued watching for replacement windows.

Access hotkeys

Assign global hotkeys that temporarily bring a hidden helper back when you need to interact with it.

End-session cleanup

Choose which applications should close when the session ends and restore hidden windows safely.

Dedicated App Startup page

Application startup settings live in their own workspace rather than being duplicated in Preferences.

PROFILES & PREPARATION

Keep every stream format organized.

Multiple profiles

Website preparation

Reusable checklists

Readiness status

Session workflow

COMMON QUESTIONS

Quick answers.

Does StreamFlight press Go Live?

No. It prepares the applications, websites and recurring checks around the stream; it does not start the broadcast itself.

Can it manage apps that should remain hidden?

Yes. Background helpers can be launched and hidden, monitored for replacement windows, then accessed temporarily with an assigned hotkey.

Can I have different setups for different games?

Yes. Profiles keep separate application, website and checklist configurations.

Do I need osu!StreamDeck?

No. StreamFlight is fully standalone.
