WHAT IT DOES

Prepare once. Start consistently.

StreamFlight keeps the applications, websites and checks used before a stream in one organized workspace.

Application startup

Add the applications used for a stream, choose their launch order and optional delays, and start the full sequence from one place.

Background helpers

Launch helper applications in the background, hide replacement windows and bring them back temporarily through assigned access hotkeys.

Website preparation

Keep dashboards, moderation pages and other browser tools in the same profile and open them during preflight.

Reusable checklists

Create recurring stream checks, mark them complete and reset them for the next session.

Multiple profiles

Maintain different setups for different games, channels or stream formats without rebuilding the same list each time.

Session controls

See what is running, what still needs attention and which helper applications should close when the session ends.

Optional osu! companion

Use StreamFlight independently or pair it with osu!Requests when the stream includes osu! map requests and overlays.

COMMON QUESTIONS

Quick answers.

Does StreamFlight start the broadcast?

No. It prepares the applications, sites and checks around the stream; it does not press Go Live.

Can it manage apps that should remain hidden?

Yes. Background helpers can be launched and hidden, then accessed temporarily with an assigned hotkey.

Do I need osu!Requests?

No. StreamFlight is fully standalone. osu!Requests is an optional companion for osu! streamers.

PLAY osu!?

Let chat send the maps.

osu!Requests handles Twitch beatmap requests, queue rules, filters, history, ranked tracking and stream overlays.
