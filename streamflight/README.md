# StreamFlight

**A Windows application-startup and pre-stream preparation workspace for streamers.**

> ### Streamer tools by ValoCookie
> StreamFlight organizes the applications, websites and checks used before going live.  
> Play osu!? **[Check out osu!Requests →](https://github.com/ValoCookie/osu-Requests)** for Twitch requests, OBS overlays, a Key Visualizer and Ranked Play tracking.

## Latest release

The newest public build is always available from **[GitHub Releases](https://github.com/ValoCookie/streamflight/releases/latest)**.

## What it does

- ordered application startup with optional delays
- drag-and-drop application setup
- background helper hiding and access hotkeys
- dedicated App Startup workspace
- websites attached to each stream profile
- reusable pre-stream checklists
- multiple profiles for games, events or formats
- readiness status and end-of-session cleanup controls
- optional osu!Requests companion workflow

StreamFlight deliberately prepares the stream around OBS; it does not press Go Live for you.
